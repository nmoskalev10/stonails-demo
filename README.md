# Сайт спа-салона с админкой

Демонстрационный проект для портфолио: одностраничный сайт спа-салона и
админка к нему. Тексты, цены, фотографии и отзывы правятся через
веб-интерфейс, без правки кода.

**Салон «Кедр и соль» выдуман.** Услуги, цены, контакты и отзывы —
вымышленные, телефон и ник в мессенджерах нерабочие. Совпадения с
существующими салонами случайны.

## Как устроено

Своего сервера нет: всё выполняется в браузере. GitHub Pages отдаёт
статические файлы, а база, вход в админку и хранилище фотографий — это
Supabase, к которому браузер ходит напрямую.

Страница рисуется из снимка `js/data.js` мгновенно и обновляется из базы в
фоне, поэтому работает даже когда база недоступна.

Чтобы подключить свою базу, заполните `js/config.js`. Пока поля пустые,
сайт живёт на снимке, а админка честно скажет, что сохранять некуда.

## Контент

Весь текст сайта лежит в `js/data.js`. Услуга — это набор секций, а секция
рисуется одним из четырёх способов (`layout`): обычный список, плитки с
заголовками, плитки со звёздочкой, плитки с подсписками. Поэтому в админке
можно собрать новую услугу, а не только поправить существующую.

## Фотографии

Изображения в `assets/photos` нарисованы кодом — `tools/gen_photos.py`
(нужны Pillow и numpy):

```
python3 tools/gen_photos.py
```

Это не фотосъёмка, а стилизованные иллюстрации в палитре сайта: в реальном
проекте на их место через админку загружаются снимки салона.

## Цвета сайта

Девять готовых тем в `js/themes.js`, выбор — в админке, на вкладке
«Главное». Тема хранится в данных (`settings.theme`) и подставляется в
переменные `:root` при загрузке.

Тема задаёт не только цвета, но и структурные вещи: шапка бывает светлой и
тёмной, кнопка — сплошной и с переходом. Глубокие оттенки (`--*-deep`)
подобраны так, чтобы белый текст на них читался; это проверяется при сборке
`js/themes.js` через `tools/themes_def.py`.

## Реквизиты и правовые документы

Реквизиты и контакты лежат в `settings.legal` и правятся в админке. В
демоверсии они намеренно пустые: у выдуманного салона нет ни ИНН, ни
настоящего юридического лица.

## Публикация

`.github/workflows/deploy.yml` заливает файлы по FTP на обычный хостинг.
Запускается вручную, кнопкой на вкладке Actions; нужны секреты `FTP_HOST`,
`FTP_USER`, `FTP_PASSWORD`, `FTP_DIR`.

# stonails — сайт школы маникюра

Лендинг с курсами и админкой, через которую владелица сама меняет тексты,
цены, фотографии и отзывы.

- Сайт: https://nmoskalev10.github.io/stonails-demo/
- Админка: https://nmoskalev10.github.io/stonails-demo/admin.html

Контент хранится в Supabase, фотографии — в его хранилище. Страница
рисуется из снимка `js/data.js` и обновляется из базы в фоне, поэтому
работает даже когда база недоступна.

Ключ в `js/config.js` — публичный: сам по себе он ничего не открывает,
права разграничены на стороне базы (читать может любой, менять — только
вошедший в админку).

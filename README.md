# Лендинг с админкой

Статичный сайт-лендинг и админка к нему: тексты, цены, фотографии и отзывы
правятся через веб-интерфейс, без правки кода.

Данные предыдущего владельца удалены по его просьбе — в репозитории остался
только движок и пустая структура контента в `js/data.js`.

## Как устроено

Своего сервера нет: всё выполняется в браузере. GitHub Pages отдаёт
статические файлы, а база, вход в админку и хранилище фотографий — это
Supabase, к которому браузер ходит напрямую.

Страница рисуется из снимка `js/data.js` мгновенно и обновляется из базы в
фоне, поэтому работает даже когда база недоступна.

Чтобы подключить свою базу, заполните `js/config.js`. Пока поля пустые,
сайт живёт на снимке, а админка честно скажет, что сохранять некуда.

## Цвета сайта

Восемь готовых тем в `js/themes.js`, выбор — в админке, на вкладке
«Главное». Тема хранится в данных (`settings.theme`) и подставляется в
переменные `:root` при загрузке.

Тема задаёт не только цвета, но и структурные вещи: шапка бывает светлой и
тёмной, кнопка — сплошной и с переходом. Глубокие оттенки (`--*-deep`)
подобраны так, чтобы белый текст на них читался; это проверяется при сборке
`js/themes.js` через `tools/themes_def.py`.

## Реквизиты и правовые документы

Реквизиты, контакты и тексты политики с офертой лежат в `settings.legal` и
правятся в админке. Пустые поля на сайт не выводятся, ссылки на
`privacy.html` и `offer.html` появляются только когда у документа есть
текст.

## Публикация

`.github/workflows/deploy.yml` заливает файлы по FTP на обычный хостинг.
Запускается вручную, кнопкой на вкладке Actions; нужны секреты `FTP_HOST`,
`FTP_USER`, `FTP_PASSWORD`, `FTP_DIR`.

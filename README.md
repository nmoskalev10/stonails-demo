# stonails — сайт школы маникюра

Лендинг с курсами и админкой, через которую владелица сама меняет тексты,
цены, фотографии и отзывы.

- Сайт: https://stonails.ru
- Админка: https://stonails.ru/admin.html

Старые адреса на `nmoskalev10.github.io` продолжают работать — GitHub
перенаправляет их на домен.

Контент хранится в Supabase, фотографии — в его хранилище. Страница
рисуется из снимка `js/data.js` и обновляется из базы в фоне, поэтому
работает даже когда база недоступна.

## Цвета сайта

Восемь готовых тем лежат в `js/themes.js`, выбор — в админке, на вкладке
«Главное». Тема хранится в данных (`settings.theme`), сайт подставляет её
значения в переменные `:root` при загрузке. По умолчанию — «Дофаминовая»,
та же палитра, что была изначально.

Тема задаёт не только цвета, но и структурные вещи: шапка бывает светлой и
тёмной, кнопка — сплошной и с переходом. Глубокие оттенки (`--*-deep`)
подобраны так, чтобы белый текст на них читался; это проверяется при сборке
`js/themes.js`.

Ключ в `js/config.js` — публичный: сам по себе он ничего не открывает,
права разграничены на стороне базы (читать может любой, менять — только
вошедший в админку).

## Публикация

Сайт статический: ни PHP, ни Node на хостинге не нужны — только отдача
файлов. Всё, что делает код, выполняется в браузере; база, вход в админку и
хранилище фотографий — это Supabase, к которому браузер ходит напрямую.

Сайт отдаёт GitHub Pages с домена `stonails.ru` — файл `CNAME` в корне
репозитория и есть эта привязка. Сертификат GitHub выпускает и продлевает
сам. Изменения в `main` появляются на сайте через минуту после мержа.

Отдельно лежит `.github/workflows/deploy.yml` — заливка по FTP на обычный
хостинг. Она пригодится, если сайт когда-нибудь переедет с Pages; пока
доступы в секретах не заданы, workflow тихо пропускается и ни на что не
влияет. Чтобы включить, добавьте доступы в Settings → Secrets and
variables → Actions → New repository secret:

| Секрет | Что это |
| --- | --- |
| `FTP_HOST` | адрес FTP-сервера из панели хостинга |
| `FTP_USER` | логин FTP |
| `FTP_PASSWORD` | пароль FTP |
| `FTP_DIR` | папка сайта на сервере, например `/www/stonails.ru` |

Пока секретов нет, публикация тихо пропускается. Заливка идёт по FTPS —
пароль и файлы шифруются; если хостинг поддерживает только обычный FTP,
это видно по ошибке подключения в логе запуска.

`README.md` и `.nojekyll` на хостинг не попадают: первый нужен только в
репозитории, второй — только для GitHub Pages.

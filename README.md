# stonails — сайт школы маникюра

Лендинг с курсами и админкой, через которую владелица сама меняет тексты,
цены, фотографии и отзывы.

- Сайт: https://nmoskalev10.github.io/stonails-demo/
- Админка: https://nmoskalev10.github.io/stonails-demo/admin.html

Контент хранится в Supabase, фотографии — в его хранилище. Страница
рисуется из снимка `js/data.js` и обновляется из базы в фоне, поэтому
работает даже когда база недоступна.

Ключ в `js/config.js` — публичный: сам по себе он ничего не открывает,
права разграничены на стороне базы (читать может любой, менять — только
вошедший в админку).

## Публикация

Сайт статический: ни PHP, ни Node на хостинге не нужны — только отдача
файлов. Всё, что делает код, выполняется в браузере; база, вход в админку и
хранилище фотографий — это Supabase, к которому браузер ходит напрямую.

Изменения в `main` уезжают на хостинг сами — `.github/workflows/deploy.yml`
заливает файлы по FTP. Чтобы это заработало, один раз добавьте доступы в
Settings → Secrets and variables → Actions → New repository secret:

| Секрет | Что это |
| --- | --- |
| `FTP_HOST` | адрес FTP-сервера из панели хостинга |
| `FTP_USER` | логин FTP |
| `FTP_PASSWORD` | пароль FTP |
| `FTP_DIR` | папка сайта на сервере, например `/www/stonails.ru` |

Пока секретов нет, публикация тихо пропускается. Заливка идёт по FTPS —
пароль и файлы шифруются; если хостинг поддерживает только обычный FTP,
это видно по ошибке подключения в логе запуска.

`README.md` и `.nojekyll` на хостинг не попадают: первый нужен только в
репозитории, второй — только для GitHub Pages.

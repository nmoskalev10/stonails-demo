# stonails — демонстрационная версия

Витрина лендинга школы маникюра для показа заказчику.

Это статичная копия: без админки и без подключения к базе, весь контент
берётся из `js/data.js`, фотографии лежат рядом в репозитории. Поэтому
страница открывается всегда и ни от чего не зависит.

Рабочая версия с админкой живёт в отдельном закрытом репозитории.
